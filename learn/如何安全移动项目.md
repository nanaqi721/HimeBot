## 安全移动步骤

1. 在 `HimeBot.App → 依赖项 → 项目` 中，右键 `HimeBot.Platform.Windows` 引用，选择“删除”。

2. 在 `HimeBot.Platform.Windows → 依赖项 → 项目` 中，右键 `HimeBot.Core` 引用，选择“删除”。

3. 选择“文件 → 全部保存”。

4. 右键 Solution 中的 `HimeBot.Platform.Windows` 项目，选择：

   ```
   移除
   ```

   这里只选择“移除”，不要选择删除文件。

5. 关闭 Visual Studio。

6. 使用 Windows 文件资源管理器，把整个文件夹：

   ```
   E:\VsCodeObject\HimeBot\HimeBot.Platform.Windows
   ```

   移动到：

   ```
   E:\VsCodeObject\HimeBot\src\HimeBot.Platform.Windows
   ```

7. 重新打开根目录的 `HimeBot.sln`。

8. 右键 Solution，选择：

   ```
   添加 → 现有项目
   ```

9. 选择：

   ```
   E:\VsCodeObject\HimeBot\src\HimeBot.Platform.Windows\HimeBot.Platform.Windows.csproj
   ```

10. 重新添加两个引用：

```
HimeBot.Platform.Windows ──> HimeBot.Core
HimeBot.App ───────────────> HimeBot.Platform.Windows
```

1. 全部保存并关闭、重新打开 Solution。

最终引用应为：

```
HimeBot.App
├─> HimeBot.Core
└─> HimeBot.Platform.Windows
                      └─> HimeBot.Core
```
